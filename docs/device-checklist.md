# 실기기 수동 체크리스트

CI의 자동 테스트(Chromium 데스크톱·모바일 에뮬레이션)로 재현할 수 없는 부분입니다. 릴리스 전에 실제 기기에서 확인합니다.

## 준비

1. 같은 네트워크에 있는 PC에서 `npm run dev -- --host`를 실행합니다.
2. 기기 브라우저로 `http://<PC IP>:5173/demo/`를 엽니다.
3. 아래 표의 기기마다 모든 항목을 확인하고, 결과를 날짜와 함께 기록합니다.

| 기기 | 브라우저 |
|---|---|
| iPhone (iOS 16 이상) | Safari |
| Android 폰 | Chrome |
| Galaxy 폰 | 삼성 인터넷 |
| iPad (선택) | Safari |

## 확인 항목

### 1. 키보드 위 툴바

- [ ] 본문을 탭하면 키보드가 올라오고, 툴바가 키보드 바로 위에 붙어 나타난다.
- [ ] 화면을 스크롤해도 툴바가 키보드 위에 그대로 붙어 있다.
- [ ] 툴바 버튼을 눌러도 키보드가 내려가지 않는다(굵게, 기울임 등).
- [ ] 툴바를 좌우로 밀어 모든 버튼에 닿을 수 있다.
- [ ] 버튼이 손가락으로 누르기 충분히 크다(44px 이상).
- [ ] 본문 밖을 탭하면 툴바가 사라진다.
- [ ] 문서 끝에서 입력할 때 커서가 툴바에 가려지지 않는다.
- [ ] 전체 화면에서 키보드가 열려 있어도 마지막 줄과 글자 수 표시줄이 툴바 위에 보인다.
- [ ] 문서 중간쯤에서 `/`를 입력하면 슬래시 메뉴가 툴바에 가리지 않는다(위로 뒤집히거나 줄어든다).
- [ ] 전체 화면이나 HTML 소스 보기를 켠 채 읽기 전용으로 바뀌면 툴바에 그 모드를 끄는 버튼만 남고, 누르면 빠져나온다.

### 2. 한글 조합 입력

- [ ] 일반 문단: "안녕하세요 반갑습니다"를 입력하면 글자 빠짐, 중복, 커서 튐이 없다.
- [ ] `# ` 입력 직후 제목에서 한글 입력이 정상이다.
- [ ] `- ` 목록 안에서 한글 입력과 줄바꿈(Enter)이 정상이다.
- [ ] 표 셀 안에서 한글 입력이 정상이다.
- [ ] 굵게를 켠 상태에서 한글 입력이 정상이다.
- [ ] 조합 중(받침 입력 중)에 툴바 버튼을 눌러도 글자가 깨지지 않는다.
- [ ] 자동완성·추천 단어를 눌러도 글자가 중복되지 않는다(Android Gboard, 삼성 키보드).

### 3. 이미지

- [ ] 이미지 버튼을 누르면 아래에서 시트가 올라오고 "파일 선택"이 보인다.
- [ ] 사진 앨범과 카메라에서 이미지를 고를 수 있고, 업로드 중 진행 막대가 보인다.
- [ ] 이미지를 탭하면 툴바에 25% / 50% / 75% / 100% 너비 버튼이 나타나고, 누르면 크기가 바뀐다.
- [ ] 모바일에서는 모서리 크기 조절 손잡이가 보이지 않는다.
- [ ] 캡션을 입력할 수 있다.
- [ ] 캡션에서 Enter를 누르면 캡션은 그대로이고 이미지 다음 새 문단으로 간다(문서 끝의 이미지 포함).

### 4. 바텀시트

- [ ] 글자색, 링크, 표 버튼이 바텀시트로 열린다.
- [ ] 시트 바깥(어두운 영역)을 탭하면 닫힌다.
- [ ] 시트 위쪽 손잡이를 아래로 끌면 닫힌다.
- [ ] 링크 시트의 주소 입력칸에 입력할 때 키보드가 시트를 가리지 않는다.

### 5. 표 편집

- [ ] 표 시트에서 6×6 격자를 탭해 원하는 크기로 넣을 수 있다.
- [ ] 셀을 탭하면 툴바가 표 도구(행·열 추가, 삭제, 병합)로 바뀐다.
- [ ] 넓은 표는 가로로 스크롤된다.
- [ ] 체크리스트 상자를 탭한 뒤 바로 입력해도 글자가 본문에 들어간다.

### 6. 회전과 화면 크기

- [ ] 가로·세로로 돌려도 툴바와 시트 위치가 맞다.
- [ ] 태블릿 가로 모드처럼 넓은 화면에서는 데스크톱 툴바로 바뀐다.

### 7. 다크 모드

- [ ] OS를 다크 모드로 바꾸면(`theme: 'auto'`) 에디터, 툴바, 시트가 모두 어두운 색이 된다.
- [ ] 다크 모드에서 붙여넣은 글자(Word, 웹)가 잘 보인다.
- [ ] 다크 모드에서 색을 칠한 표 칸(셀 배경색, Word·스프레드시트 음영)의 글자가 잘 보인다.

### 8. 붙여넣기

- [ ] 메모 앱, 카카오톡, 웹페이지에서 복사한 글을 붙여넣으면 깨진 스타일 없이 들어온다.
- [ ] 스크린샷을 붙여넣으면 업로드된다(업로드 설정 시).
